## 1. Reconhecimento de Entidades Nomeadas (NER) para Bebidas

**Modelo com Deep Learning:**  
[NERwithDeepLearning](https://github.com/PriscillaIA/NERwithDeepLearning)

**Dataset personalizado:**  
[cachacaNER_Dataset](https://github.com/PriscillaIA/cachacaNER_Dataset)

### Descrição:
Projeto completo de reconhecimento de entidades nomeadas (NER) em textos que mencionam cachaça. O pipeline envolve:

- Criação e anotação de um dataset próprio
- Pré-processamento textual
- Treinamento de um modelo BiLSTM-CRF
- Avaliação dos resultados

**Tecnologias e ferramentas usadas:**
`Python`, `spaCy`, `TensorFlow`, `Keras`, `BiLSTM`, `NER`, `pandas`, `scikit-learn`
